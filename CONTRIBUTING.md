# Contributing

This repository takes bug reports and feature requests as issues. It does not accept pull requests; they are closed without review.

Before opening an issue:

- Check the [wiki](https://wiki.playuptime.com/multiplayer/dedicated-server), in particular the troubleshooting page.
- Search existing issues.

A useful bug report includes the compose file or `docker run` line with the password removed, the output of `docker logs`, the game version, and what you expected to happen.

Problems with the game itself, rather than with the image or the egg, go through the game's own bug reporting.
